# TeenTalk — Лендинг для тестирования идеи

## Как подключить Яндекс.Метрику

### Шаг 1: Создайте счётчик
1. Зайдите на [metrika.yandex.ru](https://metrika.yandex.ru)
2. Создайте новый счётчик для вашего сайта
3. Скопируйте номер счётчика

### Шаг 2: Вставьте код счётчика
Откройте файл `index.html` и раскомментируйте блок Яндекс.Метрики:

```html
<!-- Замените XXXXXXXX на ваш номер счётчика -->
<script type="text/javascript">
  (function(m,e,t,r,i,k,a){...})(window, document, "script", "https://mc.yandex.ru/metrika/tag.js", "ym");
  ym(XXXXXXXX, "init", { ... });
</script>
```

### Шаг 3: Укажите ID в коде
Откройте файл `src/App.tsx` и замените:

```typescript
const YANDEX_METRIKA_ID = 'XXXXXXXX'; // <-- Ваш номер счётчика
```

### Шаг 4: Создайте цели в Яндекс.Метрике
В настройках счётчика создайте следующие цели:

| Название цели | Описание |
|---|---|
| `cta_button_click` | Нажатие на любую CTA-кнопку |
| `email_submit` | Отправка email в модальном окне |

### Отслеживаемые события

В коде уже настроена отправка двух типов целей:

1. **`cta_button_click`** — срабатывает при нажатии на любую кнопку "Оставить заявку" / "Узнать подробнее" / "Заинтересовало"
2. **`email_submit`** — срабатывает при отправке формы с email

## Структура лендинга

- **Hero** — главный экран с заголовком и CTA
- **Статистика** — цифры для доверия
- **Проблема** — почему это важно
- **Как это работает** — 4 шага
- **Конфиденциальность** — ключевой блок о приватности
- **Что получают родители** — ценность для ЦА
- **FAQ** — частые вопросы
- **Финальный CTA** — повторный призыв к действию
- **Модальное окно** — форма сбора email

## Кастомизация

- Название сервиса: замените "TeenTalk" в коде
- Цветовая схема: основной цвет `violet-600` (фиолетовый)
- Текст: все тексты в `src/App.tsx`
